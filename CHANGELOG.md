# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-25

### Added

- Terminal group chat with the strongest Claude and GPT models on your own subscriptions.
- Blind first answers, then free discussion; `@claude` / `@gpt` addressing; a turn budget.
- Read-only experts with web access: Claude without Bash, Codex in a read-only sandbox.
- `/stop`, `/budget N`, `/close` with a drafted decision and the other expert's objections, `/quit`.
- History in the native terminal scrollback, redrawn on resize; English and Russian interface.
- Claude Code skill that opens the chat in a new iTerm2 window and returns only the decision.
